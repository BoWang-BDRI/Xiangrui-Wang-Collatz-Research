## 1. Dyadic base map

For positive odd integers define

\[
A(n)=\operatorname{oddpart}(n+1).
\]

Every positive odd integer \(n>1\) has the unique decomposition

\[
\boxed{n=2^a q-1},\qquad
 a=\nu_2(n+1)\ge1,\qquad q=A(n)<n.
\]

Thus the power lifts

\[
P_a(q)=2^a q-1
\]

give a complete dyadic generation tree on the positive odd integers, rooted at \(1\).

## 2. Standard accelerated edge grammar

Define

\[
U(n)=\operatorname{oddpart}(3n+1).
\]

For positive odd \(p,q\),

\[
\boxed{U(p)=q\iff3p+1=2^bq\iff p=\frac{2^bq-1}{3}}
\]

for an exact integer \(b\ge1\).

Consequently:

- \(3\nmid q\): \(q\) is **LIVE** and has infinitely many exact odd predecessors;
- \(3\mid q\): \(q\) is a **SOURCE** in the accelerated odd graph and has no odd predecessor.

No third odd-interface type is required by the exact inverse grammar.

The bottom-level chain is written as

\[

\[
\boxed{U(P_a(q))=P_{a-1}(3q)}.
